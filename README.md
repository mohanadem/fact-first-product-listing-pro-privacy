# Fact-First Product Listing Pro — V2.0

Commercial redesign of the original SEO Product Sheet Generator for Capafy.

## What changed in V2
- New positioning: **Facts First, Marketing Second**.
- Product Readiness Snapshot before drafting.
- Five operating modes: CREATE, OPTIMIZE, LOCALIZE, A/B TEST, AUDIT.
- Dedicated Trust & Claim Audit.
- Stronger separation between confirmed facts, seller claims, unknowns and research data.
- Marketplace-aware output without pretending to be an official marketplace compliance checker.
- More commercially focused Agent Card.
- Four smoke-test scenarios, including optimization safety.
- Revised suggested launch price for experimentation; Capafy pricing UI remains authoritative.

## Package
- `SKILL.md` — V2 runtime instructions.
- `prompt.txt` — model prompt.
- `output_template.md` — output contract.
- `inputs.json` — conversational intake schema.
- `config.json` — maintainer metadata.
- `PUBLISH_TO_CAPAFY.md` — Agent Card and publishing guidance.
- `TEST_CASES.md` — Capafy test scenarios.
- `main.py` — original local helper, retained for structural validation.
- `SKILL_V1.md`, `prompt_V1.txt`, `output_template_V1.md`, etc. — archived V1 files for comparison.

## Important scope
The Skill does not contain a live keyword database, marketplace API, competitor crawler or ranking predictor. Numeric SEO research is only reported when an actual source/tool is available.

## Recommended commercial message
**Turn raw product information into conversion-ready product listings without letting AI invent product claims.**
